# Дневник смен водителя

FastAPI + SQLite, клиент — одна HTML-страница, которую раздаёт сам сервер.

## Запуск
```
pip install -r requirements.txt
uvicorn app.main:app --reload
```
Открыть http://127.0.0.1:8000 (при первом старте база заполняется из `data/trips.json`).
Документация API: http://127.0.0.1:8000/docs

## Тесты
```
python -m pytest
```

## API
- `GET /api/trips?day=YYYY-MM-DD` — поездки за день (по часовому поясу +05:00, по времени начала)
- `GET /api/summary?day=YYYY-MM-DD` — число поездок, выручка, комиссия, «на руки» (выручка − комиссия), разбивка нал/карта
- `POST /api/trips` — добавить поездку. `201` — создана, `200` — такая же уже есть (дубль не создаётся), `409` — тот же `id` с другими данными, `422` — ошибка валидации

## Решения
- Дубли отсекает `PRIMARY KEY` по `id`, а не проверка перед вставкой, поэтому гонка двух запросов тоже безопасна. Клиент держит один `id` до успешной отправки, так что повторный клик не создаёт вторую поездку.
- Валидация: сумма > 0, окончание позже начала, комиссия от 0 до суммы, время обязательно с часовым поясом, способ оплаты `cash`/`card`.
- Деньги — целые числа (тенге), без float.
- Допущение: «на руки» = выручка − комиссия.
